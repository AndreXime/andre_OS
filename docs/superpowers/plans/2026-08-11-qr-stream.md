# QrStream Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tool client-side que transmite texto/arquivo entre dispositivos via stream animado de QR Codes (TX + RX).

**Architecture:** Domínio puro (`protocol`, `presets`, `assemble`, `transmitter`, `receiver`) + UI React com abas; encode com `qrcode`, decode com `BarcodeDetector` e fallback `jsqr`.

**Tech Stack:** React 19, TypeScript, Astro, `qrcode`, `jsqr`, `lucide-react`, classes de `src/lib/toolUi.ts`.

## Global Constraints

- Nomes: pasta/`target` `QrStream`; slug `transmissao-optica-qr`; title `Transmissão óptica QR`
- Sem storage persistente; sem fountain codes; layout coluna até `lg`
- UI em pt-BR; sem `any`; sem em dash
- Sem commits a menos que o usuário peça
- Verificação: `npm run lint` e `npm run build` (sem test runner no repo)
- Seguir `tools.md` e spec `docs/superpowers/specs/2026-08-11-qr-stream-design.md`

### Task 1: Dependências + domínio puro

**Files:**
- Create: `domain/base64.ts`, `presets.ts`, `protocol.ts`, `assemble.ts`
- Modify: `package.json` via npm install

**Produces:**
- `bytesToBase64` / `base64ToBytes`
- `STREAM_PRESETS`, `DEFAULT_PRESET_ID`, `getPreset`
- `StreamManifest`, `buildFrames`, `parseFrame`, `ParsedFrame`
- `assemblePayload(chunks, total)`

- [ ] **Step 1:** `npm install qrcode jsqr` e `npm install -D @types/qrcode @types/jsqr` (se existirem)
- [ ] **Step 2:** Implementar base64 sem spread em arrays grandes (`btoa`/`atob` em chunks)
- [ ] **Step 3:** Implementar presets conforme spec
- [ ] **Step 4:** Implementar protocol: `TOTAL = 1 + ceil(bytes/chunkSize)`; frame 0 `0|TOTAL|M|<b64(json)>`; dados `i|TOTAL|<b64>`
- [ ] **Step 5:** `parseFrame`: split limit 3; manifesto se payload começa com `M|`; senão data chunk
- [ ] **Step 6:** `assemblePayload`: concatena índices `1..total-1` em ordem
